# GRFS

Global-to-Regional Forecast System    
_which can run global MPAS+JEDI on top of the rrfs-workflow(MPAS+JEDI)_

### Currently supported platforms
-   NOAA RDHPCS Hera
-   NOAA RDHPCS Jet
-   NOAA RDHPCS Gaea C6
-   MSU-HPC systems (Hercules/Orion)
